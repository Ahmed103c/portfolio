Projet DevOps

Pipeline CI/CD &
Infrastructure Cloud

Conception et mise en place d'une infrastructure DevOps complète pour une application cloud-native, incluant l'automatisation du déploiement, le monitoring et la gestion de l'infrastructure as code.

Vue d'ensemble du Pipeline

01

Code & Versionning

Gestion du code source avec Git, stratégie de branching GitFlow, et revue de code systématique via Pull Requests.

02

Build & Test

Compilation automatisée, exécution des tests unitaires et d'intégration, analyse de qualité du code avec SonarQube.

03

Conteneurisation

Construction d'images Docker optimisées multi-stage, push vers un registre privé (ACR/Docker Hub).

04

Déploiement

Déploiement automatique sur Kubernetes avec stratégie blue/green, rollback automatique en cas d'échec.
